# Azizi File Manager

مدير ملفات Native لنظام Android 11 وAndroid 12، بواجهة عربية RTL.

## المزايا الأساسية
- تصفح الذاكرة الداخلية.
- فتح المجلدات والملفات.
- نسخ وقص ولصق ونقل الملفات والمجلدات.
- إنشاء مجلدات وإعادة التسمية والحذف.
- البحث داخل المجلد والبحث الشامل.
- إظهار وإخفاء الملفات المخفية.
- معلومات الملف والحجم وتاريخ التعديل.
- ضغط وفك ضغط ZIP.
- مشاركة وفتح الملفات عبر تطبيقات Android المناسبة.
- صلاحية الوصول إلى جميع الملفات لأجهزة Android 11/12.
- بناء APK تلقائي عبر GitHub Actions.

> المشروع Native Android وليس WebView.
